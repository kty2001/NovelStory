  6. 6접힌 구간 칩 ≈ 6~40: 클릭 시 펼침. 구간 안 블록은 숨기지 않고 압축 표시 (UC-15)
  7. 7event-block 라인 표시: 메인 2px 실선 · 서브 1.5px 실선 · 사이드 1.5px 점선 · 미지정 테두리 없음 + 제목 아래 라인 배지. 진한 회색 = 핵심 사건, 연한 회색 = 일반 사건 (UC-10 · 23)
  8. 8기간 사건: 가로 폭 = 기간, 양 끝 지시선이 시작·끝 눈금을 가리킴. 선택 시 양 끝 핸들 (B-2, UC-11)
  9. 9state-block: ▲ 등장 · ◆ 변화(속성 변경 요약) · ▼ 퇴장(진한 채움). 좌측에 캐릭터 이름, 위로 축까지 지시선 (UC-12)
  10. 10포스트잇(sticky-note) · 자유 텍스트(board-text). 더블클릭 / F2 인라인 편집, Esc 종료 (UC-17)
  11. 11frame: 좌상단 바깥 제목. 이동 시 소속 요소 함께 이동, 삭제 시 요소 유지, 중첩 불가 (UC-18)
  12. 12board-edge: 화살표 + 가운데 라벨, 실선/점선. 선 더블클릭 → 라벨·종류 편집 (UC-19)
  13. 13도구 모음에서 끌어 놓는 중: 반투명 블록 + 스냅될 눈금까지 세로 가이드 + 눈금 번호. Alt 누르면 스냅 해제 (UC-10)
  14. 14줌 컨트롤(−, %, +, 화면 맞춤) + 미니맵(현재 뷰 사각형 드래그). 줌 0.5 미만이면 블록은 제목만 간략 표시 (UC-21)
